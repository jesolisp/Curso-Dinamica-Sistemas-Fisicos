## 📚 Requisitos Académicos
Para un adecuado seguimiento de este curso, se requiere contar con conocimientos sólidos previos en:
1. Cálculo I y II.
2. Álgebra Lineal.
3. Geometría Analítica.
4. Ecuaciones Diferenciales I y II.
5. Variable Compleja.

## 💻 Requerimientos Técnicos y Herramientas
Para ejecutar los cuadernos interactivos y realizar las prácticas, es indispensable contar con:
- **Entorno de programación:** MATLAB y MATLAB Simulink.
- **Entorno de desarrollo:** Python y Jupyter Notebook.
- **Sistema Operativo:** Windows 10, Linux, o macOS.
- **Navegador Web:** Google Chrome, Mozilla Firefox u Opera.
- **Herramientas adicionales:**

  - Uso de un sistema de control de versiones (ej. Git).

## 📖 Contenido Temático

| Unidad | Tema | Contenido |
|:---:|:---:|:---|
| **I** | **Introducción a la dinámica de los sistemas lineales** | <ul><li>Conceptos básicos.</li><li>Modelos analíticos de estudio de sistemas.</li></ul> |
| **II** | **Antecedentes matemáticos** | <ul><li>Álgebra Lineal.</li> <li>Ecuaciones Diferenciales.</li> <li> Transformada de Fourier. </li> <li> Transformada de Laplace. </li></ul> |
| **III** | **Modelado en el dominio de la frecuencia** | <ul><li> Función de Transferencia. </li> <li> Modelado de sistemas mecánicos. </li> <li> Modelado de sistemas eléctricos y electro-mecánicos. </li> <li> Modelado de sistemas hidráulicos y térmicos. </li> <li> Otro tipo de sistemas. </li></ul> |
| **IV** | **Modelado en el dominio del tiempo** | <ul><li> Ecuaciones en variables de estado. </li> <li> Modelado de sistemas mediante ecuaciones de estado. </li> <li> Relación entre el modelo en variables de estado y la función de transferencia. </li></ul> |
| **V** | **Análisis de dinámicas de sistemas en el dominio del tiempo** | <ul><li> Respuesta en el tiempo. </li> <li> Análisis de los puntos de equilibrio. </li> <li> Estabilidad de los puntos de equilibrio. </li></ul> |
